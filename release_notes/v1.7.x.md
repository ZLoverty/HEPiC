# v1.7.x

## v1.7.0

### 高倍镜头硬件兼容

为了改善老挤出测试平台对挤出熔丝直径测量精度的问题，我们引入了更高倍率的镜头。虽然高倍镜头确实能够提高测量精度，但随之而来的问题是软件 UI 的剧烈卡顿。经过对图像处理流程的各个步骤进行 profiling，发现卡顿的根因是需要处理的图像在镜头更换后增大了数倍，导致每帧的处理时间增加至将近 1 秒。为解决这个问题，我们采取了两个措施：

- 硬件端采取 2x2 binning，降低传输到软件端的像素数
- 软件端在处理前降采样，保证每帧处理的像素数与前版本接近

由于当前使用的默认画幅与 1.6.x 之前的版本有别，所以以高倍镜头的引入与兼容定义这个新的版本。
