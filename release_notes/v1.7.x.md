# v1.7.x

## v1.7.1

### 通信与实时性

- **提升挤出速度显示的实时性**：将计米器速度计算窗口从 100 个采样点缩短为 20 个采样点，并引入 EMA（指数移动平均）滤波，在降低计米器量化噪声的同时减少显示延迟。
- **加快速度值初始化**：连接建立或重连后不再等待整个缓存窗口填满，收到两个有效采样点即可开始计算速度，避免速度长时间显示为 0。
- **改进速度计算稳定性**：速度计算改用单调时钟，避免系统时间校准影响经过时间；断线时同步清空计米器缓存和 EMA 状态，防止旧连接数据影响重连后的速度值。

### 文档

- **补全文档截图**：补充并更新连接、主页、视觉、红外、G-code、数据处理和质检等功能页面及控件的实际截图，完善用户文档的图文说明。
- **精简文档首页**：移除首页中已不再维护的架构概览内容，避免与项目实际结构不一致。

### 开发工具

- **新增版权代码导出工具**：添加 `tools/copyright_export.py`，用于提取和整理项目源代码，便于版权相关材料生成与维护。

## v1.7.0

### 高倍镜头硬件兼容

为了改善老挤出测试平台对挤出熔丝直径测量精度的问题，我们引入了更高倍率的镜头。虽然高倍镜头确实能够提高测量精度，但随之而来的问题是软件 UI 的剧烈卡顿。经过对图像处理流程的各个步骤进行 profiling，发现卡顿的根因是需要处理的图像在镜头更换后增大了数倍，导致每帧的处理时间增加至将近 1 秒。为解决这个问题，我们采取了两个措施：

- 硬件端采取 2x2 binning，降低传输到软件端的像素数
- 软件端在处理前降采样，保证每帧处理的像素数与前版本接近

由于当前使用的默认画幅与 1.6.x 之前的版本有别，所以以高倍镜头的引入与兼容定义这个新的版本。
